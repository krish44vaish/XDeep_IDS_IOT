# Handling Imbalanced and Noisy Data

Real-world cybersecurity datasets are highly skewed and noisy. By integrating SMOTE-ENN, the project:

- Improves minority class detection (critical for rare attacks)
- Reduces noise and false positives
- Enhances overall model robustness

# Feature Optimization

Using a Genetic Algorithm for feature selection adds significant value:

- Eliminates redundant and irrelevant features
- Reduces computational cost and training time
- Enables efficient experimentation on high-dimensional data

# High-Performance Models

The project demonstrates state-of-the-art performance across datasets:

- BiLSTM: 99.36% accuracy & 99.35% recall (CIC-IoT-23)
- Decision Tree: 99.93% accuracy & 99.52% recall (NF-BOT-IoT)

This highlights the strength of combining:

Classical ML (interpretability & speed)
Deep Learning (temporal pattern recognition)
